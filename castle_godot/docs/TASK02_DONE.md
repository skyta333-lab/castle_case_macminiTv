## 连续时间流逝

```gdscript
@export var start_time_of_day: float = 12.0     # 启动时刻（小时）
@export var day_length_seconds: float = 180.0   # 3 分钟走完 24h，可在检查器调整
@export var transition_seconds: float = 1.2     # 预设切换过渡时长
@export var cycle_smoothing_seconds: float = 0.4 # 自动昼夜每帧平滑时长
```

自动昼夜按关键帧插值（00:00/05:00 夜 → 06:30 黄昏 → 09:00/16:30 白天 → 18:00 黄昏 → 20:00 夜），
所有颜色 / 能量 / 雾 / 曝光在相邻关键帧之间线性插值，每帧再用 0.4s 时间常数做一次平滑，切换无跳变。

太阳与月亮共用同一盏 `DirectionalLight3D`，角度按时间连续推进：

- 白天：高度角 `62°·sin(π(t-6)/12)`（12:00 最高 62°，6:00 / 18:00 落在地平线）；
- 夜间：高度角取预设月光值，方位角从日落的 70° 继续同向缓慢西移，06:00 回到日出点；
- 全程不做角度取模，实测相邻 5 分钟最大角度跳变 **7.3°**，无 180° 反向绕圈。

## 夜景策略（性能优先）

1. **天空 / 环境光 / 曝光 / 雾一起变**，不是单纯把太阳调暗：天顶色降到 (0.019, 0.031, 0.086)、天空亮度 0.55、曝光 0.90、环境光 0.28、雾密度 0.0022 且雾色转冷蓝。
2. **窗户暖色自发光**：`Win_` 节点共 **273 个网格**，运行时按源材质名去重后只生成 **2 份共享 `StandardMaterial3D` 副本**（`ALBEDO` 不变、只改 `EMISSION`），夜间 `emission_energy_multiplier = 2.60`（暖色 (1.0, 0.722, 0.376)）。
3. **零新增实时灯**：全场景没有新增任何 `OmniLight3D` / `SpotLight3D`，夜间照明成本 ≈ 1 盏平行光 + 材质自发光。
4. **轮廓可辨认**：月光 0.17 + 环境光 0.28 + 天顶亮度 0.032，保证城堡塔尖、屋顶轮廓在夜景下依旧可读（自检断言"夜景不是全黑"）。
5. **不污染原始资源**：`materials/env_day.tres` 只在启动时读取一次用于初始化，之后全部改运行时副本，自检确认磁盘资源未被改写。

## 已知性能影响

| 项 | 影响 |
| --- | --- |
| 窗户自发光 | 首次切换时创建 2 份材质副本（一次性，< 1ms）；此后仅改参数，无逐帧成本 |
| 天空 / 雾 / 曝光插值 | 每帧约 30 个浮点插值，可忽略 |
| Glow / SSAO | 沿用原有后处理，夜晚 Glow 强度提高会让高光区 bloom 略增，可在画质档下调低 |
| 影子 | 未新增光源，阴影贴图数量不变 |
